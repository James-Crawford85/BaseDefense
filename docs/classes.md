# Steel Tide — Tank Classes

Three chassis, each a stat spread + one signature perk. Numbers are starting
points to tune in playtest. Stats not listed start at their neutral baseline for
every class (Regen 0, Lifesteal 0, Projectile Speed ×1.0, AoE ×1.0) and are pure
upgrade paths. See `stats.md` for what each stat does.

## Signature perks

**Assault — Overdrive.** Getting 6 kills within 3 seconds triggers a 4-second surge:
+25% Damage and +25% Fire Rate. Rewards aggressive pack-clearing; the all-rounder
that spikes when it gets rolling.

**Heavy — Bulwark.** Starts with 40 base Shield that recharges faster (33%/s) and
sooner (2.5s delay) than anyone else. The immovable wall — leans on Shield + Armor
+ a 4th weapon slot + innate Engineering to anchor a turret line.

**Scout — Scavenger.** Enemies killed by a crit drop double gold. Ties the
crit/greed/field-gold loop together — the fast, fragile hit-and-run that gets rich
if it can stay alive.

## Identity summary

- **Assault** — safe generalist, no glaring weakness, damage edge, spikes on Overdrive.
- **Heavy** — slow fortress; soaks hits with HP/Armor/Shield, supports turrets, but
  turns and moves like a barge.
- **Scout** — glass cannon; whips around fast, crits often, gets rich, but folds if
  caught out of position.
